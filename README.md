# SERVER BREAKER 2077

Консольная игра на C++. Ты хакер и взламываешь три сервера корпорации MEGACORP. Каждый сервер закрыт паролем, а рядом дежурит **Глаз**, который с каждой твоей ошибкой раскрывается шире. Шесть ошибок, и тебя заметили.

---

## ⚠️ Сначала перейди на ветку `develop`

Все файлы проекта лежат **не в `main`, а в ветке `develop`**.

**На GitHub:**
1. Открой страницу репозитория.
2. Слева над списком файлов найди кнопку с названием ветки (там написано `main`).
3. Нажми на неё и выбери **`develop`**.

Проверь: команда `git branch` должна показать `* develop`.
